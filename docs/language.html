Language

Compact surface that lowers to Rust. Prefer the tutorial for a guided tour.

At a glance

  • Functions — one callable kind: name(args) = expr, |x| …, holes / trailing blocks / .field / .m() (examples/closures)
  • Bindings — x := value
  • Types — inferred; annotate when needed (int, str, float, …)
  • Structs — type T = { … } with field defaults
  • Enums — type Color = | Red | Custom(int, int, int) + match (string arms too, #101)
  • Methods — impl Type = { … }
  • Traits — trait / impl Trait for Type; literal/simple default bodies
  • Shapes — data shape → generated traits + structural calls (examples/shapes)
  • Generics — prefer implicit binders (id(x: T)); <> pins and applies. Operators / unique methods on T infer bounds (examples/generics_implicit, examples/shapes_generic)
  • Loops — while, for … in (vec MVP), loop, break / continue, value break expr; chained else if (#117, examples/loops)
  • Collections — implicit vec<T> from new/push/[1.0, 2.0]; indexing xs[i] / xs[i] = v (#119 / #120, examples/vec_ops)
  • Numbers — int widens to float in a checking position; postfix as float / as int; unary - on float stays float (#112 / #113). Prelude exp/sin/cos/tanh/sqrt (#115, examples/math)
  • Rust crates — rust = true deps, including local path = "…" (#105); typed extern rust crate { … } / .crpi sidecars (#116, examples/path_dep); use serde_json { … } (or use rust.…)
  • Errors — ambient !, throw, catch → Result<T, CrispError>
  • Modules — one file = one module; nested use of functions and types emits crate:: (examples/nested_math, examples/nested_types)
  • Tests — test, test_compile_fail; names are unique per module (#102)
  • Async / FFI — async, await, extern "C"

Comments: -- and nested {- -}. Interpolation: "hello {name}". Exponentiation: **.

Snippets

Short, copyable patterns. Guided tour: tutorial.

Struct + defaultstype
type ServerConfig = {
    host: str  = "127.0.0.1"
    port: uint = 9000
}

pub main() = {
    cfg := ServerConfig { port: 3000 }
    log("host={cfg.host} port={cfg.port}")
}
Enum + matchexamples/enums
type Color =
    | Red
    | Custom(int, int, int)

describe(c) = match c {
    Color.Red -> "red"
    Color.Custom(r, g, b) -> "rgb({r},{g},{b})"
}
Function valuesexamples/closures
apply(f, x) = f(x)
double(n) = n * 2

pub main() = {
    inc := |x| x + 1
    print(apply(double, 21))
    print(apply(_ * 2, 21))
    print(inc(41))
}
Implicit closuresexamples/closures
apply(f, x) = f(x)
run(f) = f(21)
label(g, p) = g(p)

type Person = { name: str }
type Vec2 = {
    x: float
    y: float
}
impl Vec2 = {
    new(x, y) = Vec2 {
        x: x
        y: y
    }
    magnitude(self) = (self.x ** 2.0 + self.y ** 2.0) ** 0.5
}

pub main() = {
    print(run { |x| x * 2 })
    print(label(.name, Person { name: "Ada" }))
    print(apply(.magnitude(), Vec2.new(3.0, 4.0)))
}
Trait + implexamples/show_trait
trait Show = { show(self) -> str }

    show(self) = "({self.x},{self.y})"
}

label(x: T) = x.show()
Data shapeexamples/shapes
shape HasPosition = {
    x: float
    y: float
}

distance(a: HasPosition, b: HasPosition) -> float = {
    dx := a.x - b.x
    dy := a.y - b.y
    dx * dx + dy * dy
}

loop {

    n = n - 1
}
