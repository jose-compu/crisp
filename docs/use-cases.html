Use cases

No production case studies yet. These are popular Rust domains where Crisp’s compact syntax and global inference are meant to make the same jobs easier to write and read — while still emitting Rust that rustc checks.

Domains Repo examples

CLI tools

Parse args, format output, exit codes — without spelling every type and borrow up front. Emit stays a normal Rust binary.

examples/hello · inventory

Config & services

Structs with defaults, modules, and sealed APIs for small services that would otherwise drown in boilerplate.

examples/defaults · server · sealed

Async workers

Tokio-backed async / await with Crisp’s lighter surface for spawn and sleep-style workflows.

examples/async_hello · async_spawn

FFI bridges

Call C with extern "C" and unsafe when you need native libraries. Rust-crate imports (use rust::) are planned.

examples/ffi

Data pipelines

Vec operations, fallible IO, and chained transforms with ambient ! error sets instead of noisy Result at every step.

examples/vec_ops · data_pipeline · fallible

Multi-module design

Organize GoF-style patterns across files with Crisp modules — good practice for larger programs before sealed publish.

examples/design_patterns · workshop

crpc run examples/hello
