Crisp

A systems language that transpiles to Rust. Explicit on demand, implicit by default — rustc remains the soundness boundary.

Get started Read the draft spec

Hello world

greet(name) = "hello " ++ name

pub main() = {
    msg := greet("world")
    print(msg)
}

Run: crpc run examples/hello → "hello world". Full steps on Getting started.

Pipeline

.crp → resolve → typeck → ownership → CIR → Rust → rustc → native
