Getting started

Full guide: QUICKSTART.md on GitHub.

Install from source

git clone https://github.com/jose-compu/crisp.git
cd crisp
cargo build --release -p crpc
export PATH="$PWD/target/release:$PATH"
# or: cargo install --path crates/crpc --locked

Hello world

Minimal program at examples/hello/src/main.crp:

-- examples/hello — minimal Crisp program (spec §5)

greet(name) = "hello " ++ name

pub main() = {
    msg := greet("crisp")
    print(msg)
}

Run it (from the repo root, with crpc on PATH):

crpc run examples/hello

Expected output:

"hello crisp"

Useful companions:

crpc check examples/hello
crpc emit examples/hello
crpc build examples/hello
crpc test examples/math
crpc check examples/design_patterns

Requires Rust 1.85+ with cargo and rustc on PATH.
