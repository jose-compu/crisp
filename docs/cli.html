CLI

crpc drives analyze → emit → Cargo. Pass a project directory (with crisp.toml).

crpc check  <path>   # resolve + typecheck (fast)
crpc emit   <path>   # write Rust under <path>/target/rust/
crpc build  <path>   # emit + cargo build
crpc run    <path>   # build + run
crpc test   <path>   # run Crisp tests via emitted Rust

Also: reveal for inferred signatures and ownership overlays (see the repo).
