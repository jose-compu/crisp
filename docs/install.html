Install Crisp

Build crpc from source with a recent Rust toolchain. Crisp emits Cargo projects, so cargo and rustc must be on your PATH.

Requirements Rust 1.85+ (see workspace rust-version) via rustup. Git clone of jose-compu/crisp.

Install from source

git clone https://github.com/jose-compu/crisp.git
cd crisp
cargo build --release -p crpc
export PATH="$PWD/target/release:$PATH"

Or install into your Cargo bin directory:

cargo install --path crates/crpc --locked
# ensure ~/.cargo/bin is on PATH

Verify:

crpc --version

Run hello world

From the repository root:

crpc run examples/hello

Expected output:

"hello world"

Useful companions:

crpc check examples/hello
crpc emit examples/hello
crpc build examples/hello
