Tutorial

A beginner tour of Crisp language features. Install crpc first, then try each snippet in a project or against the repo examples.

Before you start Follow Install until crpc run examples/hello prints "hello world".
Step 01

Hello world

Functions use =. Locals use :=. pub main is the entry point.

greet(name) = "hello " ++ name

pub main() = {
    msg := greet("world")
    print(msg)
}

Run: crpc run examples/hello

Step 02

Functions and bindings

double(n) = n + n

pub main() = {
    x := double(5)
    log("x={x}")
}
  • pub exports an item from the module
  • print / log write to stdout (via Rust println!)
  • Types are inferred unless you annotate
Step 03

Strings and comments

-- single-line comment
{- block comment -}

greet(name: str) = "hello " ++ name

pub main() = {
    who := "world"
    log("greet={greet(who)}")
}

Concatenate with ++. Interpolate with "{expr}".

Step 04

Types when you need them

Annotate parameters or fields when inference is ambiguous.

port(host: str, n: int) = n

Primitives include int, uint, float, bool, char, str.

Step 05

Structs and defaults

type ServerConfig = {
    host: str  = "127.0.0.1"
    port: uint = 9000
    debug: bool = false
}

pub main() = {
    cfg := ServerConfig { port: 3000 }
    log("port={cfg.port}")
}

Omitted fields use defaults. Field access works on local bindings (not directly on function parameters today — see limitations).

Step 06

Modules

One file per module under src/. Import with use.

-- src/arith.crp
pub sum(a, b) = a + b

-- src/main.crp
use arith { sum }

pub main() = {
    log("sum={sum(2, 3)}")
}

In a flat src/ tree, modules imported by main must sort before main alphabetically.

Step 07

Tests

test "greet works" = {
    assert_eq(greet("world"), "hello world")
}

test_compile_fail "unknown name" = {
    definitely_not_a_builtin()
}
crpc test .
Step 08

Fallible functions

Ambient errors use !, throw, and catch — lowered to Result<T, CrispError>.

parse_port(s) ! = {
    if s == "" then throw "empty"
    -- …
}

pub main() = {
    p := parse_port("8080") catch { e => 0 }
    log("port={p}")
}

See examples/fallible for fuller patterns.
