Known limitations

Honest gaps in the v1.5.x public release versus the draft spec. Full list lives on the main branch.

  • Not self-hosted — Rust-hosted crpc only (self-hosting → v2.0.0)
  • Shapes — data shapes work (examples/shapes); method / anonymous shapes still limited (#61)
  • Unknown Rust APIs are opaque stubs; known Result imports (serde_json, ureq) use Crisp ? (#55)
  • Trait defaults for literal/simple bodies shipped (examples/trait_defaults); bounds / dyn Trait still incomplete (#59)
  • Enums: unit/tuple variants work; recursive enums and full exhaustiveness still gap
  • Loops — while / for / loop work (examples/loops); for is vec-only MVP (no enumerate / labels yet)
  • Field access on parameters: inferred when exactly one struct has the field; else annotate (E0043)
  • crisp-lsp stdio host ships (hover, inlays, diagnostics); install with cargo install --path crates/crisp-lsp (#56)
  • Editor VSIX via ./scripts/package-vsix.sh; Marketplace listing optional (#57)
  • crates.io publish deferred; install from source (#60)

Shipped in v1.5.x: loops (§6.3), Result ?, data shapes, stdio LSP, VSIX packaging, trait default bodies — on top of v1.4 interop / Show/Eq/Ord / net+HTTP.
