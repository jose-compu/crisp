Language

Compact surface that lowers to Rust. Prefer the tutorial for a guided tour.

At a glance

  • Functions — name(args) = expr or block
  • Bindings — x := value
  • Types — inferred; annotate when needed (int, str, float, …)
  • Structs — type T = { … } with field defaults
  • Enums — type Color = | Red | Custom(int, int, int) + match
  • Methods — impl Type = { … }
  • Traits — trait / impl Trait for Type; literal/simple default bodies
  • Shapes — data shape → generated traits + structural calls (examples/shapes)
  • Loops — while, for … in (vec MVP), loop, break / continue, value break expr (examples/loops)
  • Rust crates — rust = true deps; use serde_json { … } (or use rust.…)
  • Errors — ambient !, throw, catch → Result<T, CrispError>
  • Modules — one file = one module; use m { f }
  • Tests — test, test_compile_fail
  • Async / FFI — async, await, extern "C"

Comments: -- and nested {- -}. Interpolation: "hello {name}". Exponentiation: **.

Snippets

Short, copyable patterns. Guided tour: tutorial.

Struct + defaultstype
type ServerConfig = {
    host: str  = "127.0.0.1"
    port: uint = 9000
}

pub main() = {
    cfg := ServerConfig { port: 3000 }
    log("host={cfg.host} port={cfg.port}")
}
Enum + matchexamples/enums
type Color =
    | Red
    | Custom(int, int, int)

describe(c) = match c {
    Color.Red -> "red"
    Color.Custom(r, g, b) -> "rgb({r},{g},{b})"
}
Trait + implexamples/show_trait
trait Show = { show(self) -> str }

impl Show for Point = {
    show(self) = "({self.x},{self.y})"
}
Data shapeexamples/shapes
shape HasPosition = {
    x: float
    y: float
}

distance(a: HasPosition, b: HasPosition) -> float = {
    dx := a.x - b.x
    dy := a.y - b.y
    dx * dx + dy * dy
}
Loopsexamples/loops
sum_vec(xs) = {
    total mut:= 0
    for x in xs {
        total = total + x
    }
    total
}

n mut:= 5
loop {
    if n == 0 then break n
    n = n - 1
}
Rust importexamples/rust_import
use serde_json { from_str, to_string }

pub main() = {
    v := from_str("[1, true]")
    print(to_string(v))
}
Teststest
test "greet works" = {
    assert_eq(greet("world"), "hello world")
}

test_compile_fail "unknown" = {
    definitely_not_a_builtin()
}
Async mainexamples/async_hello
pub main() = async {
    sleep_ms(1)
    print("async-ok")
}
