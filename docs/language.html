Language

Compact surface that lowers to Rust. Prefer the tutorial for a guided tour.

At a glance

  • Functions — name(args) = expr or block
  • Bindings — x := value
  • Types — inferred; annotate when needed (int, str, float, …)
  • Structs — type T = { … } with field defaults
  • Errors — ambient !, throw, catch → Result<T, CrispError>
  • Modules — one file = one module; use m { f }
  • Tests — test, test_compile_fail
  • Async / FFI — async, await, extern "C"

Comments: -- and nested {- -}. Interpolation: "hello {name}". Exponentiation: **.
