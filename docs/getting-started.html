Getting started

Full guide: QUICKSTART.md on GitHub.

Install from source

git clone https://github.com/jose-compu/crisp.git
cd crisp
cargo build --release -p crpc
export PATH="$PWD/target/release:$PATH"
# or: cargo install --path crates/crpc --locked

Run hello

crpc run examples/hello
crpc test examples/math
crpc check examples/design_patterns

Requires Rust 1.85+ with cargo and rustc on PATH.
