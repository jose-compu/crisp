Known limitations

Honest gaps in the bootstrap compiler versus the draft spec. Full list lives on the main branch.

  • Not self-hosted — Rust-hosted crpc only
  • Enums / match reliability incomplete
  • Field access on function parameters limited
  • Module load order is alphabetical in flat src/
  • use rust::crate imports not implemented yet (Cargo deps can be listed; calling Rust APIs from Crisp is tracked separately)
  • Shapes / some stdlib areas incomplete
