Language overview

Explicit on demand, implicit by default. Types, ownership, and errors are inferred; annotate when needed. Semantics are defined by lowering to Rust.

  • Structs, defaults, sealed crisp.lock
  • Ambient errors: !, throw, catch → Result<T, CrispError>
  • Modules: one file = one module; use m { f }
  • Tests: test / test_compile_fail
