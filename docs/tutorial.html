Tutorial

A beginner tour of Crisp language features. Install crpc first, then try each snippet in a project or against the repo examples.

Before you start Follow Install until crpc run examples/hello prints "hello world".
Step 01

Hello world

Functions use =. Locals use :=. pub main is the entry point.

greet(name) = "hello " ++ name

pub main() = {
    msg := greet("world")
    print(msg)
}

Run: crpc run examples/hello

Step 02

Functions and bindings

double(n) = n + n

pub main() = {
    x := double(5)
    log("x={x}")
}
  • pub exports an item from the module
  • print / log write to stdout (via Rust println!)
  • Types are inferred unless you annotate
Step 03

Strings and comments

-- single-line comment
{- block comment -}

greet(name: str) = "hello " ++ name

pub main() = {
    who := "world"
    log("greet={greet(who)}")
}

Concatenate with ++. Interpolate with "{expr}".

Step 04

Types when you need them

Annotate parameters or fields when inference is ambiguous.

port(host: str, n: int) = n

Primitives include int, uint, float, bool, char, str.

Step 05

Structs and defaults

type ServerConfig = {
    host: str  = "127.0.0.1"
    port: uint = 9000
    debug: bool = false
}

pub main() = {
    cfg := ServerConfig { port: 3000 }
    log("port={cfg.port}")
}

Omitted fields use defaults. Field access on parameters is inferred when exactly one known struct has the field; otherwise annotate the param (see limitations).

Step 06

Modules

One file per module under src/. Import with use.

-- src/arith.crp
pub sum(a, b) = a + b

-- src/main.crp
use arith { sum }

pub main() = {
    log("sum={sum(2, 3)}")
}

Flat src/*.crp modules may import each other regardless of filename order. Nested paths (e.g. src/math/vector.crp) emit a Rust module tree.

Step 07

Tests

test "greet works" = {
    assert_eq(greet("world"), "hello world")
}

test_compile_fail "unknown name" = {
    definitely_not_a_builtin()
}
crpc test .
Step 08

Fallible functions

Ambient errors use !, throw, and catch — lowered to Result<T, CrispError>.

parse_port(s) ! = {
    if s == "" then throw "empty"
    -- …
}

pub main() = {
    p := parse_port("8080") catch { e => 0 }
    log("port={p}")
}

See examples/fallible for fuller patterns.

Step 09

Enums and match

type Color =
    | Red
    | Green
    | Blue
    | Custom(int, int, int)

describe(color) = match color {
    Color.Red -> "red"
    Color.Green -> "green"
    Color.Blue -> "blue"
    Color.Custom(r, g, b) -> "rgb({r},{g},{b})"
}

Run: crpc run examples/enums

Step 10

Inherent methods

type Vec2 = {
    x: float
    y: float
}

impl Vec2 = {
    pub new(x: float, y: float) = Vec2 {
        x: x
        y: y
    }
    pub magnitude(self) =
        (self.x ** 2.0 + self.y ** 2.0) ** 0.5
}

pub main() = {
    v := Vec2.new(3.0, 4.0)
    log("mag={v.magnitude()}")
}

See examples/vec2_methods (also nested modules).

Step 11

Traits

Nominal contracts with explicit impl. Prelude also ships Show / Eq / Ord shims.

trait Show = { show(self) -> str }

type Point = {
    x: int
    y: int
}

impl Show for Point = {
    show(self) = "({self.x},{self.y})"
}

pub main() = {
    p := Point { x: 1, y: 2 }
    log("p={p.show()}")
}

Run: crpc run examples/show_trait · also examples/std_traits.

Step 12

Import a Rust crate

Declare the dependency with rust = true in crisp.toml, then import like TypeScript.

-- crisp.toml
-- [dependencies]
-- serde_json = { version = "1", rust = true }

use serde_json { from_str, to_string }

pub main() = {
    v := from_str("[1, true, \"crisp\"]")
    print(to_string(v))
}

Compat alias: use rust.serde_json { … }. Sharp edge: Rust Result currently becomes .expect(...) — see limitations.

Run: crpc run examples/rust_import

Step 13

Async

pub main() = async {
    sleep_ms(1)
    print("async-ok")
}

Run: crpc run examples/async_hello · also examples/async_spawn.
